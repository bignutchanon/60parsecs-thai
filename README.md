# 60 Parsecs! — ม็อดแปลไทย (Thai Translation)

ม็อดแปลไทยโดยแฟน (ไม่เป็นทางการ) เพิ่ม "ไทย" เป็นภาษาใหม่ในเกม ภาษาอื่นยังใช้ได้ตามเดิม
แปลข้อความในเกมทั้งหมด 6,788 ข้อความ (เมนู เหตุการณ์บนคอมพิวเตอร์ยาน การออกสำรวจ ภารกิจ ตอนจบ ความสำเร็จ)
รองรับเฉพาะ 60 Parsecs! เวอร์ชัน Steam (PC) build 22332285

**ดาวน์โหลด:** [60Parsecs-Thai.zip](https://github.com/bignutchanon/60parsecs-thai/releases/latest/download/60Parsecs-Thai.zip)
(หรือดูทุกเวอร์ชันที่หน้า [Releases](https://github.com/bignutchanon/60parsecs-thai/releases))

## ติดตั้ง
1. ปิดเกมก่อน
2. แตกไฟล์ zip แล้วดับเบิลคลิก `install.bat` — ตัวติดตั้งจะหาโฟลเดอร์เกมจาก Steam ให้เอง
   (ถ้าหาไม่เจอ จะให้วางพาธของโฟลเดอร์ที่มีไฟล์ 60Parsecs.exe เอง)
3. เข้าเกม > คลิกคอมพิวเตอร์ (เมนูหลัก) > Settings > กดช่อง Language จนขึ้น "ไทย"
   (ถ้าเปิดเกมครั้งแรก กดช่อง Language ในหน้าตั้งค่าแรกได้เลย)

ตัวติดตั้งจะตรวจไฟล์เกมก่อนว่าเป็นเวอร์ชันที่ม็อดรองรับ ถ้าไม่ตรงจะยกเลิกโดยไม่แก้ไฟล์ใดเลย
จากนั้นสำรองไฟล์เดิม 3 ไฟล์ใน 60Parsecs_Data เป็น .orig แล้วเขียนทับด้วยไฟล์ของม็อด

## ถอนการติดตั้ง
ดับเบิลคลิก `uninstall.bat` — คืนไฟล์เดิมจาก .orig ทั้ง 3 ไฟล์
หรือใช้ Steam > Properties > Installed Files > Verify integrity of game files

## ข้อควรทราบ
- ตัวหนังสือที่วาดอยู่ในภาพของเกม (ป้าย กระป๋องซุป ฯลฯ) ชื่อคนในเครดิต และชื่อเพลงยังเป็นภาษาอังกฤษ
- ถ้าเกมอัปเดต ม็อดจะหายไปและอาจใช้กับเกมเวอร์ชันใหม่ไม่ได้ (ตัวติดตั้งจะแจ้งเอง) — รอม็อดเวอร์ชันใหม่
- เจอข้อความเพี้ยน ตกขอบ หรือแปลผิด แจ้งได้ที่ [Issues](https://github.com/bignutchanon/60parsecs-thai/issues) พร้อมภาพหน้าจอ
- ใช้กับเกมแท้เท่านั้น ไม่เกี่ยวข้องกับ Robot Gentleman ผู้พัฒนาเกม ห้ามนำไปขาย
